# 🚀 WashWish Deployment Guide

This guide covers different deployment options for the WashWish Laundry Management System.

## 📋 Pre-Deployment Checklist

- [ ] All tests pass (`python manage.py test`)
- [ ] Static files collected (`python manage.py collectstatic`)
- [ ] Database migrations applied (`python manage.py migrate`)
- [ ] Environment variables configured
- [ ] Security settings reviewed
- [ ] Backup strategy in place

## 🌐 Render.com Deployment (Recommended)

### Step 1: Prepare Repository
```bash
# Ensure your code is committed and pushed to GitHub
git add .
git commit -m "Prepare for deployment"
git push origin main
```

### Step 2: Create Render Account
1. Go to [Render.com](https://render.com)
2. Sign up with your GitHub account
3. Authorize Render to access your repositories

### Step 3: Create Web Service
1. Click "New +" → "Web Service"
2. Connect your GitHub repository
3. Configure the service:
   - **Name**: `washwish-laundry-system`
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate`
   - **Start Command**: `gunicorn detergee.wsgi:application`

### Step 4: Environment Variables
Add these environment variables in Render dashboard:

```env
SECRET_KEY=your-super-secret-key-here
DEBUG=False
PYTHON_VERSION=3.9.18
DATABASE_URL=postgresql://... (auto-generated by Render)
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password
ALLOWED_HOSTS=your-app-name.onrender.com
```

### Step 5: Database Setup
1. Create PostgreSQL database in Render
2. Link it to your web service
3. The `DATABASE_URL` will be automatically set

### Step 6: Deploy
1. Click "Create Web Service"
2. Wait for the build to complete
3. Your app will be available at `https://your-app-name.onrender.com`

## 🐳 Docker Deployment

### Local Docker Setup
```bash
# Build the image
docker build -t washwish .

# Run with environment variables
docker run -p 8000:8000 \
  -e SECRET_KEY=your-secret-key \
  -e DEBUG=False \
  washwish
```

### Docker Compose
Create `docker-compose.yml`:

```yaml
version: '3.8'

services:
  web:
    build: .
    ports:
      - "8000:8000"
    environment:
      - SECRET_KEY=your-secret-key
      - DEBUG=False
      - DATABASE_URL=postgresql://postgres:password@db:5432/washwish
    depends_on:
      - db
    volumes:
      - ./media:/app/media

  db:
    image: postgres:13
    environment:
      - POSTGRES_DB=washwish
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=password
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

Run with:
```bash
docker-compose up -d
```

## ☁️ AWS Deployment

### Using AWS Elastic Beanstalk

1. **Install EB CLI:**
```bash
pip install awsebcli
```

2. **Initialize EB:**
```bash
eb init washwish
```

3. **Create environment:**
```bash
eb create washwish-prod
```

4. **Deploy:**
```bash
eb deploy
```

### Using AWS EC2

1. **Launch EC2 instance** (Ubuntu 20.04 LTS)

2. **Connect and setup:**
```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install Python and dependencies
sudo apt install python3 python3-pip python3-venv nginx postgresql postgresql-contrib -y

# Clone repository
git clone https://github.com/yourusername/washwish.git
cd washwish

# Setup virtual environment
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Setup database
sudo -u postgres createdb washwish
sudo -u postgres createuser washwish_user

# Configure environment
export SECRET_KEY=your-secret-key
export DEBUG=False
export DATABASE_URL=postgresql://washwish_user:password@localhost/washwish

# Run migrations
python manage.py migrate
python manage.py collectstatic
python manage.py populate_data

# Setup Gunicorn
pip install gunicorn
gunicorn --bind 0.0.0.0:8000 detergee.wsgi:application
```

3. **Configure Nginx:**
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location /static/ {
        alias /path/to/washwish/staticfiles/;
    }

    location /media/ {
        alias /path/to/washwish/media/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 🔧 Environment Configuration

### Production Settings

Create `.env` file:
```env
# Security
SECRET_KEY=your-super-secret-production-key
DEBUG=False
ALLOWED_HOSTS=yourdomain.com,www.yourdomain.com

# Database
DATABASE_URL=postgresql://user:password@host:port/database

# Email
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password

# Static Files
STATIC_URL=/static/
MEDIA_URL=/media/

# Security Headers
SECURE_SSL_REDIRECT=True
SESSION_COOKIE_SECURE=True
CSRF_COOKIE_SECURE=True
```

### Security Checklist

- [ ] `DEBUG=False` in production
- [ ] Strong `SECRET_KEY` (50+ characters)
- [ ] `ALLOWED_HOSTS` properly configured
- [ ] HTTPS enabled
- [ ] Database credentials secure
- [ ] Email credentials secure
- [ ] Regular security updates

## 🔄 CI/CD Pipeline

### GitHub Actions Example

Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy to Render

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v2
    
    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.9
    
    - name: Install dependencies
      run: |
        pip install -r requirements.txt
    
    - name: Run tests
      run: |
        python manage.py test
    
    - name: Deploy to Render
      run: |
        curl -X POST ${{ secrets.RENDER_DEPLOY_HOOK }}
```

## 🆘 Troubleshooting

### Common Issues

**Static files not loading:**
```bash
python manage.py collectstatic --clear
```

**Database connection errors:**
```bash
# Check DATABASE_URL format
echo $DATABASE_URL

# Test connection
python manage.py dbshell
```

**Memory issues:**
```bash
# Check memory usage
free -h

# Restart services
sudo systemctl restart nginx
sudo systemctl restart your-app-service
```

**SSL certificate issues:**
```bash
# Check certificate
openssl s_client -connect yourdomain.com:443

# Renew Let's Encrypt certificate
sudo certbot renew
```
